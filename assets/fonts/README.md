Cochineal font assets
====================

Unmodified Cochineal-Roman.otf and Cochineal-Bold.otf, distributed with the
Cochineal font package by Michael Sharpe, based on Crimson by Sebastian Kosch.

Package: https://ctan.org/pkg/cochineal
